# 기능요구사항
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

# 설계

---
## Use Case
1. 사용자가 경주에 참가시킬 자동차 이름을 입력
2. 사용자가 경주의 턴 지정
3. 모든 턴이 끝난 후, 우승 자동차 확인

## 객체(Object)
1. Car
   - 역할: 경주 구성
   - name
   - distance

2. Race
   - 역할: 경주 전체를 관리(참가 차량, 경주, 우승자 찾기)
   - cars
   - step

## 구현(Method)
1. Car
   - 이름 지정
   - 확률에 따른 이동
     - 경주 시작 시, 턴마다 자동차는 60% 확률로 한 칸 전진한다.
   - 이동거리에 따른 상태 출력
2. Race
   - 턴 지정: 사용자 입력을 받아 해당 경주의 턴을 지정
   - 자동차 구성: 사용자 입력을 받아 경주 차량을 구성
   - 경주 진행: 구성된 자동차들로 턴동안 경주를 진행
   - 우승자 찾기: 턴 종료 후, 가장 멀리 간 우승차량 찾기

## 예외처리
1. Car
   - 이름 지정: 자동차의 이름은 다섯글자를 넘길 수 없다. // 예외_1_1
2. Race
   - 턴 지정: 턴은 양의 정수여야 한다. (음수, 0, 실수 불가) // 예외_2_1
   - 자동차 구성: 자동차들의 이름은 ","로 구분된다. (다른 구분자 불가) // 예외_2_2
   - 우승자 찾기: 공동 우승자가 나올 수 있다. // 예외_2_3
