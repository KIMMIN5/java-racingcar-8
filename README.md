# 기능요구사항
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

# 설계

---
## Use Case
1. 사용자가 경주에 참가시킬 자동차 이름을 입력
2. 사용자가 경주의 턴 지정
3. 모든 턴이 끝난 후, 우승 자동차 확인

## 객체(Object)
1. domain
   1. Car
      - 역할: 경주 구성
   2. CarMoveRule
      - 역할: 자동차 이동 규칙
   3. Race
      - 역할: 경주(참가 차량, 경주, 우승자 찾기)
2. view
   1. UserView
      - 역할: 사용자 입출력
3. controller
   1. RaceController
      - 역할: 경주 제어
   2. Converter
      - 역할: 사용자 입출력 ↔️ 도메인 객체

## 구현(Method)
1. domain
   1. Car
      - 이름 지정
      - 이동
   2. CarMoveRule
      - 자동차 이동 조건: 0~9 사이의 정수 중 4 이상의 숫자가 나올 시 한 칸 이동
   3. Race
      - 자동차 구성: 경주 참가차량을 구성
      - 경주 시작: 구성된 자동차들로 경주를 진행 (한 턴)
      - 우승자 찾기: 가장 멀리 간 우승차량 찾기
2. view
   1. UserView
      - 턴수 입력: 사용자가 경주를 몇 턴 동안 진행할 지 입력
      - 자동차 입력: 사용자가 경주에 참여할 자동차를 이름으로 입력
      - 경주 진행 현황 출력: 자동차들의 이름과 거리 출력
      - 우승차량 출력: 경주의 우승차량을 출력
3. controller
   1. RaceController
      - 경주 시작: 
   2. Converter
      - 자동차 변환(문자열 > 리스트): ","를 기준으로 이름 분리 후, 자동차 객체를 담은 리스트로 변환
      - 턴 변환(문자열 > 정수): 사용자가 입력한 턴(문자열)을 정수형으로 변환
      - 경주 현황 변환(리스트 > 문자열): 한 턴 동안 이동한 자동차들의 이름과 거리를 문자열로 변환
      - 우승 자동차 변환(리스트 > 문자열): 우승 자동차들의 이름과 거리를 문자열로 변환
## 예외처리
1. domain
   1. Car
      - 이름 지정: 
        - 자동차의 이름은 다섯글자를 넘길 수 없다. // 예외_1_1
   2. Race
      - 우승 자동차 변환:
          - 공동 우승자가 나올 수 있다. // 예외_1_2
2. Controller
   1. Converter
      - 자동차 변환: 
        - 자동차들의 이름은 ","로 구분된다. (다른 구분자 불가) // 예외_2_1
        - 공백은 자동차 이름이 될 수 없다. // 예외_2_2
        - 빈 값은 입력할 수 없다. // 예외_2_3
      - 턴 변환: 
        - 턴은 양의 정수여야 한다. (음수 불가) // 예외_2_4_1
        - 턴은 양의 정수여야 한다. (0 불가) // 예외_2_4_2
        - 턴은 양의 정수여야 한다. (실수 불가) // 예외_2_4_3
        - 턴은 양의 정수여야 한다. (문자 불가) // 예외_2_4_4
        - 빈 값은 입력할 수 없다. // 예외_2_4_5
